# Revalidation History

Originality Revision v2 changed the opening mystery from:
- Lily sees an unknown young man;
- Max hears Lily but cannot see her;
- "is he a ghost?" as the early local question;

to:

**room anomaly → anonymous intelligence → writing → voice → first sight**

The first Gate 3 v2 review found one **MAJOR control issue**:

The old Initial Knowledge Matrix remained static until the first successful mutual reality test.

That no longer fit v2 because Max receives his own truthful POV **before** that test.

A truthful Max POV may let the reader know:
- Max is alive;
- Max has Velaire memories;
- Max has family/recovery concerns;

while Lily still does not know who or what is affecting Unit 4B.

Corrections:
- replaced the static Initial Knowledge Matrix with **K0 / K1 / K2 staged knowledge**;
- separated reader knowledge from protagonist mystery state;
- revised RW-0/RW-1/RW-2 around room-before-person discovery;
- created a v2 opening evidence ladder for M-001/M-002;
- added a writing-before-voice fairness rule;
- tightened F-001 so it cannot imply early person sight;
- revised the Twist Registry minor-twist pool to remove reliance on the old one-way visual premise;
- added an explicit v2 opening non-leak guard;
- aligned Continuity with staged knowledge.

A repository sweep then found no active default-branch match for the old opening mystery terms:
