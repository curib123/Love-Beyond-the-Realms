# 1. Why This Pass Was Required

Arc 1 already passed canon and publication QA, but several test-heavy chapters used clean, functional exchanges that could read too much like:
- question → answer;
- test instruction → result;
- technical report → technical response.

The revision goal was to make dialogue feel written by a professional fiction author without changing story facts.

The pass targeted:
- reaction before response;
- interruptions;
- hesitation;
- physical business;
- silence;
- subtext;
- character-specific humor;
- asymmetric rhythm;
- sharper emotional turns;
- fewer debug-console-style writing exchanges.

# 2. New Locked Writing Standard

Authoritative file:
`manuscript/WRITING-RULES.md`

Added hard rule:
**Cross-World Writing Channel Vitality Rule**

Core requirement:
The Lily/Max writing channel must feel like two people talking, not a debug console.

Future manuscripts must preserve:
- simple natural English;
- close third-person limited;
- human dialogue;
- scene movement;
- romance/romcom priority;
- slice-of-life grounding;
- mystery and sci-fi as supporting engines.
