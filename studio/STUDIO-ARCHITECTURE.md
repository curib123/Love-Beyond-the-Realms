# Love Beyond the Realms — Studio Architecture

## Governance

This repository uses the same gated studio-production philosophy as the reference project, adapted for a young-adult supernatural romance.

Each editorial role owns a specific canon domain. Lower-level artifacts cannot redefine higher-level canon without an explicit revision.

## Canon Hierarchy

**Series Constitution → World Bible → Realm Systems → Character Bible → Mystery Bible → Location Inventory → Volume Architecture → Chapter Roadmap → Scene Architecture → Manuscript → QA → Canon**

## Production Flow

### Phase 1 — Foundation
Series Director → World Bible → Aster House → realm geography → realm history → cosmology → Veil → crossing → memory/echo rules → Logic QA.

### Phase 2 — Characters
Character Bible → Lily → Max → supporting cast → histories → personal goals → relationships → Character QA.

### Phase 3 — Mystery
Writer Truth → M-IDs → F-IDs → false beliefs → reveal windows → payoff architecture → Mystery QA.

### Phase 4 — Location Inventory
Catalog only locations already supported by the World Bible → classify story potential → protect reveal-heavy locations → Location QA.

### Phase 5 — Volume
Select a compatible location cluster → define local/emotional conflict → relationship movement → supernatural pressure → midpoint → reversal → climax → resolution → Volume QA.

### Phase 6 — Chapter Roadmap
Chapter Architect maps each approved volume movement into chapters without writing final scenes or prose.

### Phase 7 — Scene Architecture
Every chapter receives detailed scene architecture and pre-manuscript QA.

### Phase 8 — Manuscript
Manuscript Author → Lily Voice → Dialogue → Romance → Emotion → Suspense → Atmosphere → Prose.

### Phase 9 — Chapter QA
Canon → continuity → knowledge → relationship stage → supernatural mechanics → emotional truth → prose → final chapter QA.

### Phase 10 — Canonization
Lead Editor approval → Series Director approval if high canon changed → Canon Librarian updates authoritative records.

## No-Skip Rule

Major ideas may not jump straight from inspiration to manuscript.

Examples:
- first touch requires relationship and crossing authorization;
- a parent-related revelation requires Mystery authorization;
- a new realm requires World Bible authorization;
- a new supernatural ability requires Systems authorization;
- a breakup/reconciliation requires Relationship-State authorization.

## Canon States

**LOCKED** — cannot change casually.  
**CANON** — approved story fact.  
**PROVISIONAL** — usable for planning but revisable.  
**PLANNED** — authorized future use, not yet prose canon.  
**DRAFT** — written but not canonized.  
**DEPRECATED** — retained only as historical reference.

## Single Source of Truth

Each domain has one authoritative Bible.

Supporting planning files may reference canon, but they may not redefine it.
