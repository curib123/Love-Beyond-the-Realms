## Production Flow

### Phase 1 — Foundation
Series → World → Twinfall history → Realm Systems → Echo Exchange → Phase Lag → Crossing → Foundation QA.

### Phase 2 — Characters
Lily → Max → supporting cast → independent goals → relationship chemistry → Character QA.

### Phase 3 — Mystery and Twists
Writer Truth → M-IDs → F-IDs → minor twist pool → major twist locks → reveal windows → Mystery QA.

### Phase 4 — Locations
Use World Bible locations only → classify story capacity → protect reveal-heavy locations.

### Phase 5 — Active Arc
Choose one location cluster → define romcom engine → character pressure → mystery → sci-fi focus → reversal → climax → resolution → Arc QA.

### Phase 6 — Chapter Roadmap
Set chapter count for the active arc only.

### Phase 7 — Scene Architecture
One POV per scene → dialogue purpose → comedy → relationship → mystery → sci-fi rule → consequence.

### Phase 8 — Manuscript
Manuscript Author → POV owner editor → Dialogue → Romcom → Romance → Mystery → Sci-Fi Clarity → Prose.

### Phase 9 — Chapter QA
Canon → POV → dialogue → comedy → relationship → mystery → twist fairness → sci-fi rules → continuity → prose.

### Phase 10 — Canonization
Lead Editor → owning specialists → Canon Librarian.

## No-Skip Rule

Do not jump major ideas directly into prose.

Examples:
- a major twist must enter the Twist Registry first;
- a new crossing ability must enter Realm Systems first;
- a romance milestone must match relationship state;
- a new regular POV must be authorized;
- a future arc cannot become canon only because it sounds exciting.

## Open-Ended Rule

The studio does not lock the final series length.

Plan deeply only where needed for the active production state.

## Canon States

**LOCKED • CANON • PROVISIONAL • PLANNED • DRAFT • DEPRECATED**

## Single Source of Truth

Each canon domain has one authoritative source.

Lower documents may use canon but may not silently redefine it.
